# Mansoor Shaik — GitHub Pages Portfolio

A responsive, minimal portfolio built with plain HTML, CSS, and JavaScript. No build tools or dependencies are required.

## Before sharing publicly

- Add your own résumé PDF to this repository as `resume.pdf`.
- In `index.html`, replace `YOUR.EMAIL@example.com` with the public email address you want to share.
- Replace the LinkedIn placeholder with your profile URL, or remove that link.
- Replace the three sample project cards with real projects, accurate descriptions, and their repository/demo links. They are placeholders, not claims about completed work.
- Replace sample skill labels with languages and tools you genuinely use.

## GitHub Pages

This repository is named `sman786786.github.io`, the expected user-site repository name. In GitHub, open **Settings → Pages** and select **Deploy from a branch**, branch **main**, folder **/(root)**, then save. Publishing may take a few minutes.

Site URL: https://sman786786.github.io/

This is a static website. The email link opens the visitor's mail app; there is no message backend. Never commit passwords, API keys, or private information.
